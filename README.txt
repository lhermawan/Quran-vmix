
QURAN LIVE STREAM SYSTEM (vMix Ready)

FILES

overlay.html
Auto ayat overlay using Quran API.

control.html
Operator control panel.

mushaf.html
Display mushaf page.

SETUP IN VMIX

1 Add Browser Input
   load overlay.html

2 Add Browser Input
   load mushaf.html?p=1

3 Open control.html in browser

Operator controls:
- Change surah / ayah
- Next / prev ayah
- Jump directly to Juz

Use overlay.html?s=2&a=5
to show specific verse.

Recommended layout:

Camera (left)
Mushaf (right)
Overlay ayat bottom
